# Licensing

This repository is a collection of independently licensed artifacts. There is
no repository-wide default license.

Each artifact's license is identified in `catalog.yaml` and included in that
artifact's directory:

- `artifacts/reusefirst`: Apache-2.0, with the complete terms in
  `artifacts/reusefirst/LICENSE-APACHE-2.0`
- `artifacts/constitution`: MIT
- `artifacts/asc`: MIT

Files outside those artifact directories are repository documentation and do
not grant additional rights beyond the license attached to each artifact.
