# Security Policy

## Scope

The artifacts in this repository are local, dependency-free, advisory tools.
They do not provide sandboxing, authorization, isolation, or protection against
a malicious host or consumer agent.

## Reporting

Do not disclose suspected vulnerabilities in a public issue. Private
vulnerability reporting was not enabled for `edoworks/artifacts` or
`edoworks/factory` when checked on 2026-10-09. Use the existing contact-request
fallback in [edoworks/factory](https://github.com/edoworks/factory/issues/new):
state only that a private security contact is needed for an Edoworks artifact.
Do not include vulnerability details, sensitive data, secrets, or attachments
in that public request. This is a request for a private contact, not a private reporting
channel.

## Support boundary

The maintainers review supported release lines on a best-effort basis. Each
artifact's README and release notes define its compatibility and limitations.
There is no guarantee of suitability for legal, medical, financial, privacy,
security, or release decisions.

## Maintenance

The repository maintainers own release review, issue triage, and security
response. Release records state their observed immutability; current releases
are mutable. Corrections use a new version rather than rewriting an existing
artifact version.
